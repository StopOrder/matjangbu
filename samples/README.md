# samples — 가공 데이터

여기 있는 이름·금액·상호·구역은 **전부 지어낸 값**이다. 실존 개인·단체 정보는 들어 있지 않다.
`tools/make_samples.py`가 표에서 결정론으로 만든다(난수 없음). 손으로 고치지 말고 생성기를 고친다.

| 파일 | 무엇 |
|---|---|
| `roster.csv` | 명부 60명(id·이름·구역·세대·옛이름). 세대 칸에 세대주 이름(비신도)을 적은 사람이 둘 있다 |
| `aliases.json` | 미리 쌓인 별칭 1건(회사 명의) |
| `weeks/2026-W10.csv` … `W13.csv` | 은행 내려받기 형식의 입금 내역 4주(출금 줄 1개 포함) |
| `answers.json` | 주차별 원문 → 정답 id (체험 화면의 「샘플 정답 대조」에만 쓴다) |
| `envelopes/2026-W10.json` | 봉투 입력 1주 12줄(계수 총액 포함) |
| `held_lines.json` | 벤치용 「확인 필요 줄」 30건 — 여섯 유형 × 5, 규칙 1·2단으로 풀리지 않는 것만 |

```bash
python3 tools/make_samples.py          # samples/ 재생성
```
