먼저 체험해 보기

무엇이 필요한가요

조건은 하나, CPU 가 있을 것. 그래픽카드는 필요 없어요.

  • CPUx86-64 또는 ARM64, 코어 2개 이상. 스레드 수는 코어 수의 절반부터 시험해 보세요.
  • 메모리4GB. 모델이 약 1GB 를 쓰고 문맥은 2048 토큰이에요. 4GB 폰에서도 돌렸어요.
  • 저장공간2GB. 모델 파일과 작업공간 폴더를 합쳐서요.
  • 파이썬3.10 이상. pip 으로 받을 패키지는 없어요. (npm 은 체험 화면을 빌드할 때만 쓰고 실행에는 필요 없어요.)
  • llama.cpp릴리스의 CPU 빌드 하나를 풀면 llama-server 가 나와요. MIT.
  • 모델 파일Qwen2.5-1.5B-Instruct Q4_K_M(Apache-2.0) gguf 하나. 저장소에는 들어 있지 않아요.
  • 인터넷모델 파일을 받을 때 한 번만요. 그 뒤로는 없어도 켜져요.

설치 순서

네 줄이에요. 아래 명령은 저장소에 실제로 있는 것만 적었어요.

# 1) 저장소를 받아요. 모델 파일은 ~/models/qwen1.5b.gguf 로 따로 받아 둡니다
git clone https://github.com/StopOrder/matjangbu && cd matjangbu

# 2) 작업공간을 만들어요 — 명부 CSV(id,이름,구역,세대,옛이름)를 함께 넣습니다
python3 -m engine init ~/맞장부 --roster 명부.csv

# 3) 모델 서버를 띄워요(포트 8107). --run 을 빼면 명령만 보여 줍니다
python3 -m engine serve --model ~/models/qwen1.5b.gguf --run

# 4) 화면을 열어요 — 브라우저에서 http://127.0.0.1:8108/try/
python3 -m web --workspace ~/맞장부
127.0.0.1 로만 여세요. 로그인이 없는 화면이라 --host 0.0.0.0 으로 열면 같은 망의 누구나 장부를 볼 수 있어요. 모델 서버가 없어도 규칙 2단까지는 돌고, 남은 줄은 「모델 미실행」으로 표시돼요.

기기 사양을 재서 모델과 스레드 수를 골라 주는 설치기와 zip 은 준비 중이에요준비 중

폴더 하나가 단체 하나예요

설치하면 이 폴더가 생겨요. 여기 있는 것이 전부이고, 전부 엑셀이나 메모장으로 열려요.

~/맞장부/
  명부.csv          id,이름,구역,세대,옛이름 — 엑셀로 편집해요
  들어옴/           은행 CSV 를 넣는 곳(화면에서 올려도 여기 저장돼요)
  내보내기/         주간명단·개인별누적·연말합산 CSV
  .matjangbu/
    aliases.json    별칭 사전 — 사람이 고른 답이 쌓여요
    lines.jsonl     줄 대장 — 지우지 않고 덧붙이기만 해요
    imports.jsonl   불러온 파일 대장 — 같은 파일은 다시 넣지 않아요

대장은 덧붙이기만 하는 파일이라 되돌리기도 새 줄로 남아요. 지워지지 않습니다.

백업은 폴더 복사예요

그 컴퓨터가 고장 나도 폴더 하나만 있으면 새 PC 에서 그대로 이어가요.

복사할 것

~/맞장부/ 폴더 통째로 하나예요. USB 나 단체 드라이브에 주일마다 복사해 두세요.

되살리는 법

새 PC 에 저장소와 모델을 다시 올린 뒤, 복사해 둔 폴더를 그대로 놓고 python3 -m web --workspace 로 가리키면 끝이에요.

자동 백업 준비 중

USB·단체 드라이브로 자동 복사하고 암호를 거는 기능은 아직 없어요. 지금은 사람이 직접 복사합니다.

담당자가 바뀔 때

인터뷰에서 가장 먼저 나온 질문이었어요. 넘길 것은 셋뿐이에요.

  • 작업공간 폴더

    ~/맞장부/ 하나를 넘겨요. 명부·대장·별칭 사전·내보낸 파일이 전부 여기 있어요. 따로 옮길 데이터베이스가 없습니다.

  • 별칭 사전

    「이 글자는 이 사람」이라는 판단이 aliases.json 에 쌓여 있어요. 전임자 머릿속이 아니라 파일에 있으니, 후임자는 첫 주부터 같은 자동 확정을 받아요.

  • 명부 CSV

    엑셀로 열리는 한 장이에요. 세대 칸에 세대주 이름을 적어 두면 가족 명의 이체가 규칙으로 후보에 걸립니다.

후임자가 화면에서 새로 배울 것은 「이 사람이 맞습니까」 하나예요. 나머지는 매주 하던 일 그대로입니다.
