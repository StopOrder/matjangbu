## 개정 — 토스(TDS) 전면 적용 (2026-09-21 오후, 사용자 지시)

사용자 지시 「토스 TDK 참고해서 개편해줘」에서 출발했다. 조사 결과 **「TDK」는 토스 공식 명칭이 아니다** — 개발자센터 304개 문서·`github.com/toss`·npm 전수 조사에 없고, 정식 명칭은 **TDS(Toss Design System)**다. 'TDK'는 앱인토스 미니앱 툴킷을 외부 개발자들이 「Toss Design/Development Kit」으로 자의적으로 줄여 부른 말이다. 데스크톱 웹 규격의 정본은 `toss.im`·`tossbank.com`·`tosspayments.com` 프로덕션 CSS의 `--pc-*` 토큰이고, 색 토큰만 `@toss/tds-colors`가 공개 npm이다. 조사 정본: `~/Projects/00-research/2026-09/w4/2026-09-21-toss-tdk/FINDINGS.md`(각주 46개).

### 사용자가 위험을 듣고도 고른 것
조사는 고밀도 장부 화면에서 리스트가 깨지는 이유 넷을 댔다 — ①행·열 교차 대조 불가 ②FHD 한 화면 10~12행(표는 24행) ③대량 입력 효율 저하 ④키보드 연속 조작 무력화. 토스 자신도 데스크톱 웹에는 별도 표 규격(thead 40px·`#f2f4f6`·양 끝 radius 12px)을 둔다. 이 근거를 보인 뒤에도 사용자가 **리스트**를 골랐다(2026-09-21). 그대로 간다.

### 리스트로 가면서 나비와 갈라지는 장치
화면 모양이 카드 목록에 가까워졌으므로, 구분은 다른 데서 만든다.
1. **처리 대상만 모으지 않는다** — 빈 줄과 채워진 줄이 한 흐름 안에 번호순으로 섞인다. 나비는 처리 대상만 모인 큐다.
2. **금액이 오른쪽 끝에 `tabular-nums`로 정렬되고, 바닥에 합계·계수 검산이 상시로 있다.** 나비엔 금액 개념이 없다.
3. **드로어·모달 0.** 펼침은 줄 자리에서.
4. **상단 탭 4개, 사이드바 없음.**
5. **맨 위 입력 줄** — 큐에는 사람이 줄을 넣지 않는다.
