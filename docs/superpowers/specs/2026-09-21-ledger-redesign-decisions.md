# 맞장부 UX/UI 전면 재작성 — 결정 기록 (grilling 2026-09-21)

사용자 결정 16개. 정본 스펙은 시안 확정 뒤 따로 쓴다. 이 문서는 「왜·무엇을」만 잠근다.

## 왜
지금 사이트와 앱이 **나비(nabi-core)와 너무 똑같다.** 사이트 지도(네 장)·랜딩 섹션 순서와 소제목 5개·앱 골격(사이드바 + 대시보드 + 카드 큐 + 우측 드로어)이 그대로다. 신청서에 나비가 팀의 전작으로 적혀 있어 심사위원이 둘을 나란히 볼 수 있다.
